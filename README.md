# 🏎️ 수학 곱셈 레이싱 (Math Multiplication Racing)

초등학교 4학년을 위한 수학 곱셈 학습용 웹 게임입니다. 레이싱 게임의 요소를 결합하여 학생들이 지루하지 않게 연산 연습을 할 수 있도록 돕습니다.

## 🎯 학습 목표
- 2자리 수 × 1자리 수
- 3자리 수 × 1자리 수
- 3자리 수 × 2자리 수 (초등학교 4학년 1학기 핵심)

## 🎮 게임 조작법
- **터치/드래그**: 화면의 자동차를 좌우로 드래그하여 이동합니다.
- **마우스**: 마우스를 클릭한 상태로 좌우로 드래그합니다.

## 🌟 게임 규칙
1. 화면 상단에 나타나는 곱셈 문제를 확인합니다.
2. 위에서 아래로 내려오는 세 개의 게이트 중 정답이 적힌 게이트를 자동차를 이동시켜 통과하세요.
3. 정답 통과 시: 점수 100점 획득 및 일시적인 속도 부스터 발동!
4. 오답 통과 시: 생명(❤️) 1개 감소, 자동차 흔들림 효과, 화면에 정답 표시.
5. 제한 시간 60초 또는 생명이 모두 소진될 때까지 가장 높은 점수를 달성해 보세요!
